# IT-помощник лицея №37

Веб-чат-бот для IT-отдела МБОУ «Многопрофильный лицей №37».

## Функции
- Распознавание естественного языка (NLTK) и маршрутизация по службам (плотник 103, IT 204, бухгалтерия 207, администрация 101).
- Приём заявок с записью в `requests.csv`.
- Админ-панель (вход: `администратор aaadir37@`) для просмотра, удаления и отметки заявок.

## Запуск
```bash
pip install -r requirements.txt
python app.py
